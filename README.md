# basic-monte-carlo-simulation
A basic implementation of Monte Carlo simulation for stock price prediction

## Features
- Fetches historical stock data using yfinance
- Performs Monte Carlo simulation
- Visualizes results with matplotlib

## Requirements
- Python 3.7+
- yfinance
- numpy
- matplotlib
- pandas

## Installation
```bash
pip install yfinance numpy matplotlib pandas
```

## Usage
Run the script to see the Monte Carlo simulation results for the specified stock
